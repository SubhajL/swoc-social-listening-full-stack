# RID API Integration Details

## Parameter Naming Convention
- All parameters must be lowercase
- No underscores in parameter names
- Examples:
  - stationid (not station_id)
  - timestart (not time_start)
  - hourlytimeutc (not hourlytimeUTC)

## Data Types
- Station ID: string (e.g., 'P.1')
- Time values: string (Thai calendar format)
- Measurement values: number | null
- Notation values: number

## Response Format
```typescript
interface TelemetryReading {
  stationid: string;           // Station ID (e.g., 'P.1')
  hourlytime: string;          // Local time
  hourlytimeutc: string;       // UTC time
  wlvalues: number | null;     // Water level (m)
  wlvaluesabove: number | null;// Water level above dam (m)
  qvalues: number | null;      // Flow rate (m³/s)
  qavrvalues: number | null;   // Average daily flow rate (m³/s)
  notationid: number;          // Data quality/status code
}
```
