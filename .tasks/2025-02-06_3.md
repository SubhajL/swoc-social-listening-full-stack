# Location String Formatting Task

## Overview
Task to implement proper Thai administrative location formatting in the LocationInfo component.

## Requirements

### Input Data Formats
1. Array Format (ProcessedPost type):
```typescript
{
  tumbon: string[];
  amphure: string[];
  province: string[];
}
```

2. String Format (Complaint type):
```typescript
{
  location: string;  // e.g. "และ เชียงคำ พะเยา" or "ละลาย ลอง"
}
```

### Output Format Requirements
Must format addresses according to Thai administrative levels with proper prefixes:
1. ตำบล for sub-district (tumbon)
2. อำเภอ for district (amphur)
3. จังหวัด for province

Examples:
- "ตำบลละลาย อำเภอลอง" (2 parts: tumbon, amphur)
- "ตำบลคลัง จังหวัดระยอง" (2 parts: tumbon, province)
- "ตำบลถนน จังหวัดพังงา" (2 parts: tumbon, province)
- "ตำบลเชียงคำ จังหวัดพะเยา" (from "และ เชียงคำ พะเยา")

### Edge Cases
1. Leading "และ" should be removed
2. Empty or invalid data should return "ยังไม่มีข้อมูล"
3. Must handle both 2-part and 3-part addresses correctly
4. Must detect if second part is province or amphur

## Implementation Details

### Data Processing Flow
1. Check for array data first (tumbon, amphure, province arrays)
2. If no arrays, process location string:
   - Remove leading "และ"
   - Split by spaces
   - Clean and trim parts
   - Determine administrative levels
   - Add appropriate prefixes

### Administrative Level Detection
For 2-part addresses:
1. First part is always tumbon
2. Second part could be either:
   - Province (if matches known province list)
   - Amphur (if not in province list)
