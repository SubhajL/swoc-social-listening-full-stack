# Combined API Stations

This directory contains the combined unique stations from both RID Telemetry API services:
- getHourlyStationList
- getDailyStationList

## Files

- `all_api_stations.txt`: Text file with all 367 unique station codes
- `all_api_stations.json`: JSON file with all 367 unique station codes

## Station Breakdown

- 345 stations common to both APIs
- 24 stations only in the hourly API
- 10 stations only in the daily API

## Usage

This combined list can be used to compare with the database to identify stations that exist in the database but are not available through either API service.
